## Sobre

Sou Desenvolvedor Full Stack e Analista de Sistemas, há mais de 5 anos em tecnologia. Entrego de ponta a ponta: da interface em React à API em Java ou Node.js, do banco de dados ao servidor que mantém tudo no ar.

- **Hoje** — construo e mantenho sistemas institucionais na **URCA** e administro a infraestrutura virtualizada (Proxmox/KVM) que os sustenta.
- **Pesquisa** — concluo Sistemas de Informação no **IFCE** em 2026, com TCC sobre predição de defeitos em commits usando Machine Learning e NLP.
- **Dados públicos** — no **PET-Saúde Digital**, mapeio sistemas do SUS e proponho painéis de BI para a gestão municipal.
- **Disponível** para oportunidades remotas, híbridas ou presenciais no Cariri (CE) · CLT ou PJ.

<summary><sub>Como este perfil é gerado</sub></summary>

<br>

Nenhum widget de terceiros: toda a arte desta página é SVG produzido por scripts deste repositório.

- `scripts/build-assets.mjs` gera o banner (a esfera é rotação 3D pré-calculada em keyframes SMIL), o card de stack e os cards de projeto, em tema claro e escuro.
- `scripts/build-stats.mjs` consulta a API GraphQL do GitHub e desenha o card de números.
- `.github/workflows/profile.yml` roda todos os dias, refaz o card de números e o snake e publica na branch `output`.

```bash
node scripts/build-assets.mjs        # arte estática  → assets/
node scripts/build-stats.mjs --mock  # card de números com dados de exemplo → dist/
```
